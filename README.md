# 🌌 Acerca de Spotify Clone Front-End

**Spotify Clone Front-End** es un clon del reproductor web oficial de Spotify enfocado en replicar la experiencia visual y funcional de la plataforma mediante React y consumo de APIs REST.

La aplicación permite:

- 🎵 Explorar playlists
- 🎧 Navegar artistas y álbumes
- 🔎 Buscar canciones en tiempo real
- ❤️ Acceder a bibliotecas personales
- 📚 Gestionar playlists
- 🌐 Controlar reproducción remota
- ⚡ Disfrutar una UI moderna inspirada en Spotify

El proyecto fue desarrollado para practicar:

- React Development
- Frontend Architecture
- Spotify API
- OAuth Authentication
- Custom Hooks
- Infinite Scroll
- UI/UX moderna

# ⚡ Instalación

## 1️⃣ Clonar repositorio

```bash
git clone https://github.com/isairey/Spotify-Clone-Front-End.git
```

---

## 2️⃣ Entrar al proyecto

```bash
cd Spotify-Clone-Front-End
```

---

## 3️⃣ Instalar dependencias

```bash
npm install
```

---

## 4️⃣ Ejecutar aplicación

```bash
npm start
```
